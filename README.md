# プライバシーポリシー（Privacy Policy）

RinRiS（以下、「当開発者」といいます）が提供するスマートフォン向けアプリケーション（以下、「本アプリ」といいます）における、ユーザー情報の取扱いについて、以下のとおりプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。


## 1. 個人情報の収集・送信・共有について

本アプリは、ユーザーの氏名、メールアドレス、電話番号、位置情報、デバイス固有の識別子（IPアドレス、広告ID、シリアル番号等）などの個人情報を収集、送信、保持、または第三者と共有することはありません。


## 2. 端末内データ（ローカルデータ）の利用について

本アプリでは、ゲームの進行状況（クリアステージ情報、選択した車両等）を保持するために、端末内のローカルストレージ（SharedPreferences）のみを使用しています。

これらのデータはユーザーの端末内にのみ保存され、外部サーバーや第三者に送信されることはありません。アプリをアンインストールすると、これらのデータも消去されます。


## 3. ネットワーク権限・サードパーティSDK・広告について

### ネットワーク通信権限の非要求

本アプリはインターネットアクセス権限（INTERNET権限）を必要とせず、完全オフラインで動作します。

### サードパーティSDK・分析ツール非搭載

Google Analytics、Firebase、その他のアクセス解析ツールや追跡（トラッキング）用SDKは使用していません。

### 広告の非表示

本アプリ内に広告配信システムや行動ターゲティング広告は含まれていません。


## 4. 子どものプライバシー保護

本アプリは、子どもを含むすべてのユーザーのプライバシー保護に配慮して設計されています。

本アプリでは、ユーザーから個人情報を収集、送信、保持、または第三者と共有することはありません。


## 5. プライバシーポリシーの変更

本ポリシーの内容は、法令の変更や本アプリのアップデートなどに伴い、変更される場合があります。

変更後のプライバシーポリシーは、本ページに掲載された時点から適用されるものとします。
